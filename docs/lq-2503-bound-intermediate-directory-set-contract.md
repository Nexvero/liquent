# LQ-2503 Bound intermediate directory-set contract

- Intermediate topology is a mapping from fixed names to captured identities.
- A name alone never proves continuity of a phase-output directory.
- Every retained device and inode remains controller-owned immutable evidence.
- Current type, mode, owner, and identity must hold in one descriptor traversal.
- Same-name replacement fails even when its visible metadata remains private.
- This local integrity contract grants no publication or deployment authority.
