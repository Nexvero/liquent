# LQ-2485 Publication-rollback parent contract

- Rollback authority is confined to the same parent directory bound before execution.
- An open descriptor alone cannot substitute for expected parent device and inode.
- Parent ownership must remain with the current local user.
- Parent mode drift does not broaden targets or change the fixed relative names.
- Parent identity or ownership mismatch prevents rollback non-destructively.
- This narrow recovery authority grants no deletion or external publication capability.
