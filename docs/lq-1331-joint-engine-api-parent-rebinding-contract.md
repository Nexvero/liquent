# LQ-1331 Joint engine API parent rebinding contract

- Rebinding any parent component during source capture invalidates loading.
- A symlink targeting the original parent cannot preserve path trust.
- A replacement real directory with identical content also remains distinct.
- Rejection occurs after bounded capture but before snapshot construction.
- Original source descriptors are not retargeted or retried.
- The visible chain must remain continuously represented by real directories.
- Failure remains detail-free technical unavailability.
