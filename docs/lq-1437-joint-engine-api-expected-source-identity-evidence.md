# LQ-1437 Joint engine API expected source identity evidence

- Exact descriptor identity permits the established source load.
- Negative, boolean, short, list, and textual values are rejected.
- Replacing a source directory with an identical copy is rejected.
- Rejection occurs before any acceptance marker can be created.
- Unbound standalone loading remains regression-covered.
- Tests exercise externally observable behavior, not schema choices.
- Evidence is local and does not constitute production readiness.
