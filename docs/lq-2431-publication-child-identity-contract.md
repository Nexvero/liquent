# LQ-2431 Publication child-identity contract

- Final publication retains all four captured phase-output identities.
- Workspace-root identity alone cannot substitute for child directory continuity.
- The publication boundary accepts only the controller-owned complete identity set.
- Each child must remain private, current-user-owned, real, and device/inode-equal.
- A same-named replacement before commit fails closed.
- These custody checks do not authorize publication beyond local preflight output.
