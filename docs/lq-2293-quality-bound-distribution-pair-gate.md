# LQ-2293 quality-bound distribution-pair gate

- Distribution capture requires an established quality-evidence digest.
- Canonical pair facts include it beside source and runtime provenance.
- Every later pair check requires the same immutable quality identity.
- Missing or malformed quality identity rejects fail closed.
- Equal artifact bytes under another test outcome form another pair.
- Individual test facts remain private measured phase state.
- The binding performs no test rerun or artifact mutation.
