# LQ-2409 Exact entry-point load gate

- Loading iterates the complete expected console-script identity, not discovered count alone.
- Each loaded object is selected by its exact bound name-and-target pair.
- A duplicate, absent, foreign-group, or changed entry prevents successful completion.
- The isolated loader must emit neither standard output nor standard error.
- Successful loading precedes private installed-tree normalization and measurement.
- No command is executed and no deployment or operator capability is granted.
