# LQ-2227 Wheel entry-point identity contract

- The wheel exposes exactly the reviewed Liquent console command set.
- Command names and Python targets are immutable installable facts.
- Missing, additional, renamed, or redirected commands fail closed.
- Minimum-entry checks are insufficient for executable metadata.
- One semantic digest binds the complete sorted mapping.
- One file digest binds its canonical serialized representation.
- The contract adds no command execution or installation authority.
