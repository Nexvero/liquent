# LQ-2291 quality-evidence identity contract

- Distribution provenance includes one canonical quality-evidence identity.
- Normal and PostgreSQL test runs remain distinct measured facts.
- Each run contributes its passed count and warning count.
- PostgreSQL contributes its observed server version.
- Fixed test commands identify the meaning of both count pairs.
- Quality identity is evidence and grants no release authority.
- External CI attestation remains a separate later concern.
