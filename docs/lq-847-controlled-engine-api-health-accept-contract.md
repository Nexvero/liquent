# LQ-847 — Controlled Engine API Health Accept Contract

## Ergebnis

Definiert genau einen Accept auf einem bereits geöffneten Health-Listener. Clienttimeout, Austausch und garantiertes Close bilden eine feste, fail-closed Reihenfolge.

## Grenze

Kein Listenererwerb, Loop, Prozessstart oder Production-Wiring.
