# LQ-2417 Loader-to-tree root-continuity gate

- The isolated loader is surrounded by checks of the retained root identity.
- Tree normalization accepts that identity explicitly and rejects a different root.
- The retained identity then crosses into the terminal bundle phase.
- Terminal tree remeasurement must open the same device-and-inode directory object.
- Digest equality cannot conceal deletion and reconstruction with identical bytes.
- Candidate construction starts only after identity and content continuity both pass.
