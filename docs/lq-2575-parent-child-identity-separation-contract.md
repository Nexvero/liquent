# LQ-2575 Parent-child identity-separation contract

- The workspace anchor and every expected child require distinct identities.
- No phase-output name may claim the workspace device and inode tuple.
- Separation is decided from validated entry-time identity facts.
- An aliasing expectation rejects before any filesystem observation.
- Real namespace layout cannot rehabilitate an incoherent identity mapping.
- Identity separation grants no publication, deployment, or release authority.
