# LQ-2579 Disjoint intermediate identity set

- Accepted state contains one workspace identity and zero to four child identities.
- Every identity in that combined set is pairwise distinct.
- Child names remain fixed and each name binds exactly one child identity.
- The set is a local verification snapshot, not an authority token.
- New mapped outputs extend only later controller snapshots after capture.
- No regular filesystem discovery may extend the set.
