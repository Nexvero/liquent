# LQ-2459 Atomic evidence-identity capture contract

- Controlled evidence identity originates from its exclusive creation descriptor.
- A later path lookup cannot establish the first trusted device and inode.
- Identity capture follows complete write, file synchronization, and metadata checks.
- The synchronized parent still must retain its bound workspace identity.
- Path and captured identity leave the writer together as one internal result.
- This local capture grants no deployment or external publication authority.
