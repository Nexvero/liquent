# LQ-2499 Single mapped phase-output transition

- Exactly four fixed phases may extend intermediate workspace topology.
- Each mapped phase contributes exactly its one predefined directory name.
- Identity capture follows the existing post-gate workspace and child checks.
- Unmapped phases must leave the root entry set unchanged.
- A mapped phase cannot recapture an already retained directory name.
- Caller-selected output names never become expected intermediate state.
