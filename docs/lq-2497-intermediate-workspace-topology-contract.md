# LQ-2497 Intermediate workspace-topology contract

- Workspace-root topology is exact before and after every controlled phase.
- Only phase-output directories already captured by the controller may exist.
- Future outputs, foreign files, temporary names, links, and special entries fail closed.
- Every accepted entry is a private current-user-owned real directory.
- Controlled evidence is created only after all phases, outside intermediate topology.
- This topology discipline grants no deployment or external publication authority.
