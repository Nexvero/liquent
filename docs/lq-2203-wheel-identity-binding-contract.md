# LQ-2203 Wheel identity binding contract

- Wheel filename, metadata root, project name, version, and tag agree.
- The accepted project identity is exactly liquent.
- The accepted artifact is the universal py3-none-any wheel.
- Version identity is derived from the validated filename.
- Embedded metadata cannot replace or broaden that identity.
- Missing, duplicate, foreign, or inconsistent identity fails closed.
- The contract adds no installation or publication authority.
