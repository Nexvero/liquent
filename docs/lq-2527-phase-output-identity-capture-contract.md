# LQ-2527 Phase-output identity-capture contract

- A newly mapped phase output is captured from an opened child descriptor.
- The child is resolved relative to the bound workspace without link following.
- Descriptor and visible namespace must identify the same concrete directory.
- Both observations require exact private mode and current local ownership.
- Workspace identity and metadata remain valid across the complete capture.
- Captured identity grants no authority beyond local preflight continuity.
