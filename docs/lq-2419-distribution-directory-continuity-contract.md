# LQ-2419 Distribution-directory continuity contract

- The fixed `artifacts` path must identify one directory object across all gates.
- Device and inode are bound when the private directory is exclusively created.
- Wheel and sdist content digests cannot substitute for their parent identity.
- Replacement, path reuse, deletion and recreation, or redirection fail closed.
- The binding spans build, pair verification, specialized gates, and final inventory.
- This continuity proves local evidence custody and grants no publication authority.
