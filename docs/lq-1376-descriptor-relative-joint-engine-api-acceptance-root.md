# LQ-1376 Descriptor-relative joint engine API acceptance root

- One shared helper opens the complete absolute registry component chain.
- Directory, no-follow, and close-on-exec flags apply to every segment.
- Each preceding descriptor closes immediately after successful descent.
- The final descriptor transfers to exactly one registry operation.
- Marker reads and creation remain relative to that held descriptor.
- Failure closes every descriptor still owned by traversal.
- No string canonicalization substitutes for filesystem identity.
